## Design & UI Skills

A skill is a task playbook: read its `SKILL.md` before the task it covers. All design skills from the SEVA Caregiver repo ecosystem are installed locally in `.agents/skills/` and mirrored in `.claude/skills/`.

### Core UI & Accessibility Design
- **Elder-first UI**: [.agents/skills/elder-first-ui/SKILL.md](.agents/skills/elder-first-ui/SKILL.md) — Accessible, high-clarity UI rules (type floors, tap targets ≥44/56px, choice budgets, loud completion states, plain language).
- **Impeccable**: [.agents/skills/impeccable/SKILL.md](.agents/skills/impeccable/SKILL.md) — Design director playbook for frontend polish, visual hierarchy, cognitive load, tokens, accessibility, and UX copy.
- **Hallmark**: [.agents/skills/hallmark/SKILL.md](.agents/skills/hallmark/SKILL.md) — Anti-AI-slop design system for greenfield pages, audits, and structural variety.

### Visual & Technical Diagramming
- **Diagram Design**: [.agents/skills/diagram-design/SKILL.md](.agents/skills/diagram-design/SKILL.md) — Branded architecture, flowcharts, ER/data models, sequence, and system diagrams (HTML/SVG/PNG).

### Frontend Aesthetics & High-End Craft
- **Design Taste (Frontend)**: [.agents/skills/design-taste-frontend/SKILL.md](.agents/skills/design-taste-frontend/SKILL.md) — Anti-slop landing pages, portfolios, and redesigns with real design systems.
- **High-End Visual Design**: [.agents/skills/high-end-visual-design/SKILL.md](.agents/skills/high-end-visual-design/SKILL.md) — Agency-grade typography, spacing, shadows, and card depth.
- **Redesign Existing Projects**: [.agents/skills/redesign-existing-projects/SKILL.md](.agents/skills/redesign-existing-projects/SKILL.md) — Targeted upgrades to existing interfaces without breaking functionality.
- **Emil Design Engineering**: [.agents/skills/emil-design-eng/SKILL.md](.agents/skills/emil-design-eng/SKILL.md) — Micro-interactions, component craft, and invisible details.
- **Apple Design**: [.agents/skills/apple-design/SKILL.md](.agents/skills/apple-design/SKILL.md) — Fluid physical interfaces, spring animations, materials, and gestures.
- **Minimalist UI**: [.agents/skills/minimalist-ui/SKILL.md](.agents/skills/minimalist-ui/SKILL.md) — Restrained, clean layout principles.
- **Industrial Brutalist UI**: [.agents/skills/industrial-brutalist-ui/SKILL.md](.agents/skills/industrial-brutalist-ui/SKILL.md) — High-contrast, bold structural design.
- **Pick UI Library**: [.agents/skills/pick-ui-library/SKILL.md](.agents/skills/pick-ui-library/SKILL.md) — Decision matrix for selecting component libraries.
- **Web Design Engineer**: [.agents/skills/web-design-engineer/SKILL.md](.agents/skills/web-design-engineer/SKILL.md) — Full-stack web design engineering workflows.
